# Piano Trainer 🎹

A piano training tool built with React and TypeScript.

## Features

- 🎹 Virtual piano keyboard
- ⌨️ PC keyboard input support
- 🖱️ Mouse click support
- 🎵 Real-time audio playback
- 🎼 White and black key support
- 🎶 Multi-note playback

## Tech Stack

- React
- TypeScript
- Vite
- Web Audio API
